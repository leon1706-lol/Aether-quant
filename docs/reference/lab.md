# aether_quant.lab

The model lab (V6.7.1): build datasets from closes, train the project's own networks or a linear model on them, judge the runs by the project's statistics (out-of-sample IC, decay, a cost-aware book, PSR and DSR at the trial count N), sweep, explain and export them as `aq models` zips.
